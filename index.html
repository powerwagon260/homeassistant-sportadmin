HomeAssistant SportAdmin

Private Home Assistant Integration

About this application

HomeAssistant SportAdmin is a personal, non-commercial integration developed for private home automation.

The application reads SportAdmin invitation emails from the owner's Gmail account and processes the information locally for display in Home Assistant.

How it works

The application uses the Gmail API with read-only permission. It identifies relevant SportAdmin invitations and extracts event information and attendance status.

The application does not send emails, modify Gmail messages, or provide public access to the owner's information.

Availability

This is a private application intended for personal use. It is not an official Home Assistant or SportAdmin product.
