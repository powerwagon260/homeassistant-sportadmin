Privacy Policy

HomeAssistant SportAdmin

Last updated: November 2026

Purpose

HomeAssistant SportAdmin is a private, non-commercial application for displaying SportAdmin invitations in a personal Home Assistant installation.

Google API access

The application requests read-only access to the owner's Gmail account through the Gmail API.

Application-level filtering is used to identify relevant SportAdmin invitations. The Gmail permission itself is not restricted to a specific label.

Data processing and storage

Relevant invitation details, including activity information, dates, and attendance status, are processed locally.

OAuth credentials and tokens are stored locally and are not published on this website. Invitation data is not made publicly available.

Data sharing

The application does not sell Gmail data or share it with advertisers or third-party analytics services.

Data control

The owner can stop using the application, remove locally stored data, and revoke its Google account access at any time.

Google API Services

The application's use of information received from Google APIs is subject to the Google API Services User Data Policy, including its Limited Use requirements.
